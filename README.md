# 🚀 Sobre el Proyecto

**Reinado NDT** es un juego de rol (RPG) de texto desarrollado en Java, donde te pones en la piel de un alumno que debe sobrevivir al curso escolar. En lugar de dragones, tus enemigos son los **exámenes de los profesores**. Tu misión es estudiar, mejorar tus habilidades y obtener buenas notas para ganar monedas, subir de nivel y, finalmente, enfrentarte al temible **Director en el examen final**.

✨ **Características principales:**

*   **⚔️ Combates por turnos:** Enfrenta exámenes cuya dificultad es generada aleatoriamente y pon a prueba tu conocimiento.
*   **📈 Sistema de progresión:** Sube de nivel para hacerte más fuerte y prepárate para desafíos mayores, aumentando tu **conocimiento**, **energía** y **defensa**.
*   **🛒 Tienda de mejoras:** Usa las monedas ganadas en los exámenes para comprar mejoras y recuperar tu energía.
*   **🏆 Jefe final:** Alcanza el nivel 5 y enfréntate al reto definitivo: el exigente examen del Director que decidirá si apruebas el curso.
*   **🎲 Elementos procedurales:** Profesores, dificultad de los exámenes y recompensas se generan de forma aleatoria en cada partida.

# 🧠 Contexto del Proyecto

Este proyecto fue desarrollado como una práctica de programación en Java. El objetivo era aplicar los conceptos de **Programación Orientada a Objetos (POO)** como clases (`Alumno`, `Profesor`), interfaces (`Mejorable`) y enumerados (`TipoMejora`) para crear una aplicación de consola funcional y entretenida.

# 🛠️ Stack Tecnológico

*   **☕ Java:** Lenguaje principal utilizado para toda la lógica del juego.
*   **🖥️ Consola (CLI):** La interfaz de usuario es puramente basada en texto, ejecutándose en la terminal.

# 🚀 Cómo Utilizar el Proyecto

Para ejecutar este proyecto localmente, solo necesitarás tener instalado el **JDK** (Java Development Kit).

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/evagr11/ReinadoNDT.git
    ```

2.  **Navega al directorio del proyecto:**
    ```bash
    cd ReinadoNDT
    ```

3.  **Compila todos los archivos Java:**
    Desde la carpeta `ReinadoNDT`, ejecuta el compilador. Este comando creará los archivos `.class` dentro del directorio `reinadoNDT`.
    ```bash
    javac reinadoNDT/*.java
    ```

4.  **Ejecuta el juego:**
    Una vez compilado, puedes iniciar el juego ejecutando la clase `Main`.
    ```bash
    java reinadondt.Main
    ```
